# CS361_G650-05 : ระบบจัดการการเบิกค่าตอบแทนการสอน

## วิสัยทัศน์ของโครงการ (Project Vision)

ออกแบบระบบกลางสำหรับจัดการการเบิกค่าตอบแทนการสอนและค่าตอบแทนที่เกี่ยวข้อง ซึ่งสามารถติดตามสถานะ ตรวจสอบประวัติ และสรุปข้อมูลเพื่อการบริหารจัดการได้

## ผู้ใช้งานเป้าหมาย (Primary User)

อาจารย์/ผู้สอน และผู้ช่วยสอน (TA) ที่ต้องการยื่นขอเบิกค่าตอบแทน และติดตามสถานะของคำขอ

## ปัญหาที่พบ (Problem)

ข้อมูลอาจกระจายอยู่ในแบบฟอร์ม เอกสาร หรือไฟล์หลายชุด ทำให้ผู้ขอเบิกประสบปัญหาในการขอเบิกและติดตามสถานะคำร้องขอ เช่น ต้องกรอกข้อมูลซ้ำและเจ้าหน้าที่ใช้เวลาค่อนข้างมาก เพราะต้องผ่านกระบวนการเซ็นต์เอกสาร เป็นต้น ทำให้ติดตามสถานะหรือภาพรวมได้ยาก ไม่เป็นระบบ

### สถานการณ์ปัจจุบัน

- อาจารย์ต้องคอยเซ็นเวลาสอนให้พี่เจ้าหน้าที่ และแจ้งวันชดเชย
- พี่เจ้าหน้าที่ต้องรวบรวมเวลาของอาจารย์ที่สอนทุกคน
- พี่เจ้าหน้าที่ต้องเอาเวลาสอนของอาจารย์ไปยื่นเบิก
- ต้องส่งต่อรอผู้อนุมัติพิจารณา

## วัตถุประสงค์ V1 (V1 Goal)

เป้าหมายของ V1 คือการเก็บข้อมูลความต้องการที่จำเป็นจากผู้ใช้ เพื่อสร้างระบบเบื้องต้นที่ให้ข้อมูลที่จำเป็นที่เกี่ยวข้องกับการเบิกค่าตอบแทนการสอน  

## ขอบเขตที่ครอบคลุมใน V1 (V1 In scope)

- แสดงอัตราและประเภทค่าตอบแทน
- แสดงเงื่อนไขและสิทธิ์ในการได้รับค่าตอบแทน
- แสดงเอกสารหรือหลักฐานที่ต้องใช้ในการยื่นคำร้อง
- แสดงขั้นตอนและวิธีการยื่นคำร้องผ่านระบบ
- แสดงวิธีการใช้งานฟีเจอร์เบื้องต้นของระบบ
- แสดงข้อมูลเกี่ยวกับช่วงเวลาและรอบการเปิดรับคำร้อง

## ขอบเขตที่ไม่ครอบคลุมใน V1 (V1 Out of scope)

- การจ่ายเงินค่าตอบแทนจริง
- ระบบบัญชี/การเงินของมหาวิทยาลัย
- การจัดตารางสอน
- การจัดตารางชดเชย
- กระบวนการอนุมัติที่อยู่นอกระบบ
- ระบบการยื่นใบคำร้องการเบิกค่าตอบแทน

## ผู้ใช้งานและระบบภายนอก (External Actors / Systems)

### ผู้ใช้งานภายนอก

- อาจารย์ / ผู้สอน
- ผู้ช่วยสอน (TA)

### ระบบภายนอก / แหล่งข้อมูล

- ข้อมูลตารางสอน
- ข้อมูลรายวิชา
- ข้อมูลอาจารย์และ TA
- ข้อมูลการเบิกจ่ายค่าตอบแทน
- ระบบบัญชี/การเงินของมหาวิทยาลัย

### การเป็นเจ้าของข้อมูล

- ผู้ใช้สามรถเข้าถึงข้อมูลที่จำเป็นได้
- ข้อมูลการเบิกค่าตอบแทนจะต้องมีลายเซ็นบุคลกรจริง
- เอกสารค่าตอบแทนสามารถตรวจสอบความถูกต้องได้
- ผู้ใช้ไม่สามารถเข้าถึงข้อมูลนอกเหนือจากตัวเองได้

## คำถามที่ยังเปิดอยู่ / สิ่งที่ต้องตรวจสอบ (Open Questions / To Validate)

- ข้อมูลค่าตอบแทนรายชั่วโมงมาจากที่ใด
- ข้อมูลหรือหลักฐานสามารถเป็นลายลักษณ์อักษรได้ไหม
- ผู้ยื่นต้องการติดตามสถานะคำขอในรูปแบบใด
