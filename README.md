# CS361_G650-05 : ระบบจัดการการเบิกค่าตอบแทนการสอน

## วิสัยทัศน์ของโครงการ (Project Vision)

ออกแบบระบบกลางสำหรับจัดการการเบิกค่าตอบแทนการสอนและค่าตอบแทนที่เกี่ยวข้อง ซึ่งสามารถติดตามสถานะ ตรวจสอบประวัติ และสรุปข้อมูลเพื่อการบริหารจัดการได้

## ผู้ใช้งานเป้าหมาย (Primary User)

อาจารย์/ผู้สอน และผู้ช่วยสอน (TA) ที่ต้องการยื่นขอเบิกค่าตอบแทน และติดตามสถานะของคำขอ

## ปัญหาที่พบ (Problem)

ข้อมูลอาจกระจายอยู่ในแบบฟอร์ม เอกสาร หรือไฟล์หลายชุด ทำให้ผู้ขอเบิกประสบปัญหาในการขอเบิกและติดตามสถานะคำร้องขอ เช่น ต้องกรอกข้อมูลซ้ำและเจ้าหน้าที่ใช้เวลาค่อนข้างมาก เพราะต้องผ่านกระบวนการเซ็นต์เอกสาร เป็นต้น ทำให้ติดตามสถานะหรือภาพรวมได้ยาก ไม่เป็นระบบ

### สถานการณ์ปัจจุบัน

- อาจารย์ต้องคอยเซ็นเวลาสอนให้พี่เจ้าหน้าที่ และแจ้งวันชดเชย
- พี่เจ้าหน้าที่ต้องรวบรวมเวลาของอาจารย์ที่สอนทุกคน
- พี่เจ้าหน้าที่ต้องเอาเวลาสอนของอาจารย์ไปยื่นเบิก
- ต้องส่งต่อรอผู้อนุมัติพิจารณา

## วัตถุประสงค์ V3 (V3 Goal)

เป้าหมายของ V3 คือการพัฒนารระบบให้รองรับการเข้าสู่ระบบและผู้ใช้หลายบทบาท รองรับ Workflow การยื่น ตรวจสอบ อนุมัติ ไม่อนุมัติ หรือส่งกลับแก้ไขตามลำดับขั้นที่กำหนด รวมถึงจำกัดการเข้าถึงข้อมูลส่วนบุคคล ข้อมูลการเงิน และเอกสารประกอบให้เฉพาะผู้ที่มีสิทธิ์ พร้อมจัดเก็บประวัติการดำเนินการสำคัญเพื่อให้ตรวจสอบย้อนหลังได้

## ขอบเขตที่ครอบคลุมใน V3 (V3 In scope)

- ลงชื่อเข้าใช้งานด้วยบัญชีผู้ใช้งาน
- เลือกรอบและภาคการศึกษาที่ต้องการจะยื่นคำขอ
- สร้างคำขอเบิกค่าตอบแทน
- บันทึกร่างหรือยื่นคำขอเบิกค่าตอบแทน 
- ติดตามสถานะคำขอเบิกค่าตอบแทน 
- แนบหลักฐาน
- การรองรับผู้ใช้งานหลายบทบาท
- ระบบการอนุมัติคำขอ
- ระบบ Dashboard กรองคำขอ ค้นหา จัดกลุ่ม และสรุปยอดสำหรับ Staff

## ขอบเขตที่ไม่ครอบคลุมใน V3 (V3 Out of scope)

- รองรับการเชื่อมต่อ API ของมหาวิทยาลัย
- รองรับการส่งแจ้งเตือนออกนอกเว็ปไซต์
- รองรับระบบ Dashboard สรุปข้อมูลคำขอและงบประมาณ

### ผู้ใช้งานภายนอก

- อาจารย์ / ผู้สอน
- ผู้ช่วยสอน (TA)
- เจ้าหน้าที่ / ผู้ตรวจสอบ
- ผู้บริหาร / ผู้ดูแลระบบ

### ระบบภายนอก / แหล่งข้อมูล

- ข้อมูลตารางสอน
- ข้อมูลรายวิชา
- ข้อมูลอาจารย์และ TA
- ข้อมูลการเบิกจ่ายค่าตอบแทน
- ระบบบัญชี/การเงินของมหาวิทยาลัย

### การเป็นเจ้าของข้อมูล

อาจารย์ / (TA)
- สามารถเข้าถึงบัญชีของตัวเองได้
- สามารถยื่น แก้ไข และลบคำขอของตัวเองได้เท่านั้น
- ไม่สามารถดูคำขอของคนอื่นได้
- ไม่สามารถเข้าถึงข้อมูลนอกเหนือจากตัวเองได้
- ไม่สามารถยืนยันการตรวจสอบหรืออนุมัติคำขอได้

เจ้าหน้าที่ / ผู้ตรวจสอบ
- สามารถเข้าถึงคำขอทั้งหมดได้ แต่ไม่สามารถแก้ไขหรือลบได้
- สามารถยืนยันตรวจสอบหรือส่งคืนคำขอได้
- ไม่สามารถอนุมัติหรือปฏิเสธคำขอได้

ผู้บริหาร / ผู้อนุมัติ
- สามารถเข้าถึงคำขอทั้งหมดได้ แต่ไม่สามารถแก้ไขหรือลบได้
- สามารถอนุมัติหรือปฏิเสธคำขอได้หรือส่งคืนคำขอได้
- ไม่สามารถสามารถยืนยันตรวจสอบได้
