# AWS Service ที่เกี่ยวข้อง
[สถาปัตยกรรมระบบเบื้องต้น](./AWS.png)
## 1. AWS Amplify - การ Hosting web application
AWS Amplify คือบริการ Hosting สำหรับการพัฒนาและควบคุม web application แบบ Full-stack สามารถสร้างเว็ปไชต์ได้อย่างรวดเร็ว รับรองการเชื่อมต่อกับฐานข้อมูล และรองรับทั้ง JavaScript, Mobile และ Flutter

## 2. Amazon S3 bucket - Service เก็บไฟล์
Amazon S3 bucket คือบริการเก็บข้อมูล Object ที่ช่วยให้สามารถเก็บไฟล์หลักฐานเอกสารคำร้องได้
