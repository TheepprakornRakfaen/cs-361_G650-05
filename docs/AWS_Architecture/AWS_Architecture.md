# AWS Service ที่เกี่ยวข้อง
[สถาปัตยกรรมระบบเบื้องต้น](./AWS.png)
## 1. AWS Cloudfront - การ Hosting web application
AWS Cloudfront เป็น Amazon Web Services ที่บริการเครือข่ายการจัดส่งเนื้อหา หรือ Content Delivery Network (CDN) ที่สร้างขึ้นมาเพื่อการเผยแพร่และนำเสนอเนื้อหา โดยสามารถเผยแพร่เนื้อหาได้ทั้งแบบ Static หรือ Dynamic และยังมีความยืดหยุ่นในการปรับแต่งเพื่อรองรับฟีเจอร์เสริมที่มากขึ้น
## 2. Amazon Cognito - Authorization/Authentication
Amazon Cognito เป็น บริการสำหรับการยืนยันตัวตนที่ช่วยให้ผู้ใช้สามารถลงทะเบียนและเข้าสู่ระบบได้ สะดวกในการจัดการข้อมูลผู้ใช้ และปลอดภัย เหมาะสำหรับการยืนยันผู้ใช้งานฝั่งผู้ยื่นเบิกและฝั่งเจ้าหน้าที่
## 3. Amazon API Gateway - API Service
Amazon API Gateway เป็นบริการสร้าง API เป็นประตูเพื่อควบคุมทรัพยากรของระบบจาก backend
## 4. Amazon Lambda
Amazon Lambda คือบริการประมวลผลแบบ Serverless ทำให้สามารถรันโค้ดประมวลผลได้โดยที่ไม่ต้องมีเซิฟเวอร์ เหมาะกับการสร้างหน่วยประมวลผลเพื่อตรวจสอบ Request จาก User หรือการจัดเก็บข้อมูลลง Database
## 5. Amazon RDS - Database
Amazon RDS คือบริการฐานข้อมูลแบบเชิงสัมพันธ์ ซึ่งสามารถปรับขนาด (Scale) เพิ่มลดตามความต้องการใช้งานได้อย่างยืดหยุ่น เหมาะสำหรับฐานข้อมูลตารางภาคการศึกษา และข้อมูลใบยื่นคำร้อง

## 6. Amazon S3 bucket - Service เก็บไฟล์
Amazon S3 bucket คือบริการเก็บข้อมูล Object ที่ช่วยให้สามารถเก็บไฟล์หลักฐานเอกสารคำร้องได้
