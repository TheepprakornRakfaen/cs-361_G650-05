## 1. AWS Amplify - การ Hosting web application
AWS Amplify คือบริการ Hosting สำหรับการพัฒนาและควบคุม web application แบบ Full-stack สามารถสร้างเว็ปไชต์ได้อย่างรวดเร็ว รับรองการเชื่อมต่อกับฐานข้อมูล และรองรับทั้ง JavaScript, Mobile และ Flutter นอกจากนี้ Amplify ยังสามารถเชื่อมกับ Github repository เพื่อทำ CI/CD pipeline ได้โดยไม่ต้องเปลี่ยนแบบ manual โดยตรง
